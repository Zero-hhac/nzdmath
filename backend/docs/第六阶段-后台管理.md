## Step 01：设计后台管理 DTO

**目标：** 定义后台创建/更新内容的请求结构

**涉及文件：**
- 创建 `internal/dto/admin_dto.go`

**关键点：**
- 后台创建内容时需要传入的字段比前台展示更全面
- 管理员可设置 `status`（发布/草稿）和 `is_featured`（是否首页推荐）
- 校验更严格（如标题不能为空、分类必须在枚举范围内）

**关键代码片段：**

```go
package dto

// 通用后台内容创建请求（以活动为例）
type CreateEventRequest struct {
    Title       string     `json:"title" binding:"required,min=2,max=200"`
    Summary     string     `json:"summary" binding:"max=500"`
    Content     string     `json:"content" binding:"required"`
    Category    string     `json:"category" binding:"required"`
    Location    string     `json:"location" binding:"max=200"`
    StartTime   *time.Time `json:"start_time" binding:"required"`
    EndTime     *time.Time `json:"end_time"`
    CoverURL    string     `json:"cover_url" binding:"max=500"`
    Status      int        `json:"status" binding:"oneof=0 1"`         // 0=草稿, 1=发布
    IsFeatured  bool       `json:"is_featured"`
}

type UpdateEventRequest struct {
    Title       string     `json:"title" binding:"max=200"`
    Summary     string     `json:"summary" binding:"max=500"`
    Content     string     `json:"content"`
    Category    string     `json:"category"`
    Location    string     `json:"location" binding:"max=200"`
    StartTime   *time.Time `json:"start_time"`
    EndTime     *time.Time `json:"end_time"`
    CoverURL    string     `json:"cover_url" binding:"max=500"`
    Status      *int       `json:"status" binding:"omitempty,oneof=0 1"`
    IsFeatured  *bool      `json:"is_featured"`
}

// 类似定义 CreateResourceRequest, UpdateResourceRequest, CreateNewsRequest...
```

**预期效果：**
DTO 编译通过，binding tag 能正确校验。

## Step 02：实现后台管理服务层

**目标：** 实现活动/资源/资讯/作品的增删改查

**涉及文件：**
- 创建 `internal/service/admin_service.go`

**关键点：**
- 复用已有的 repository（eventRepo、resourceRepo 等）
- 创建时设置 `CreatedBy = 当前管理员ID`
- 更新时使用 `db.Model(&model).Updates(updates)` 或 `Save`
- 删除第一版可做物理删除，后续升级软删除
- 删除前建议校验内容是否存在

**关键代码片段（创建活动）：**

```go
func (s *AdminService) CreateEvent(adminID uint, req dto.CreateEventRequest) (*model.Event, error) {
    event := model.Event{
        Title:      req.Title,
        Summary:    req.Summary,
        Content:    req.Content,
        Category:   req.Category,
        Location:   req.Location,
        StartTime:  req.StartTime,
        EndTime:    req.EndTime,
        CoverURL:   req.CoverURL,
        Status:     req.Status,
        IsFeatured: req.IsFeatured,
        CreatedBy:  adminID,
    }
    
    if err := s.eventRepo.Create(&event); err != nil {
        return nil, err
    }
    
    // 创建后清除首页缓存（如果用了 Redis 缓存）
    s.homeCache.DelHomeData()
    
    return &event, nil
}
```

**预期效果：**
Service 层提供：`CreateEvent`、`UpdateEvent`、`DeleteEvent`、`GetEventList`、`GetEventDetail` 等方法。

## Step 03：实现后台管理 Handler

**目标：** 暴露 HTTP 接口，供前端后台页面调用

**涉及文件：**
- 创建 `internal/handler/admin_handler.go`

**关键点：**
- 所有接口路径前缀为 `/api/v1/admin/`
- 从 gin context 获取当前管理员 ID：`c.GetUint("user_id")`
- 统一返回格式与公开接口一致
- 列表接口支持分页 + 状态筛选（方便管理员筛选草稿/已发布）

**关键代码片段：**

```go
func (h *AdminHandler) CreateEvent(c *gin.Context) {
    adminID := c.GetUint("user_id")
    
    var req dto.CreateEventRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        response.Error(c, 400, err.Error())
        return
    }
    
    event, err := h.adminService.CreateEvent(adminID, req)
    if err != nil {
        response.Error(c, 500, "创建活动失败: "+err.Error())
        return
    }
    
    response.Success(c, event)
}

func (h *AdminHandler) UpdateEvent(c *gin.Context) {
    idStr := c.Param("id")
    id, _ := strconv.ParseUint(idStr, 10, 32)
    
    var req dto.UpdateEventRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        response.Error(c, 400, err.Error())
        return
    }
    
    if err := h.adminService.UpdateEvent(uint(id), req); err != nil {
        response.Error(c, 500, "更新失败")
        return
    }
    
    response.Success(c, nil)
}

func (h *AdminHandler) DeleteEvent(c *gin.Context) {
    idStr := c.Param("id")
    id, _ := strconv.ParseUint(idStr, 10, 32)
    
    if err := h.adminService.DeleteEvent(uint(id)); err != nil {
        response.Error(c, 500, "删除失败")
        return
    }
    
    response.Success(c, nil)
}
```

**预期效果：**
Handler 层编译通过，能正确解析 URL 参数和 JSON body。

## Step 04：注册后台路由 + 软删除改造

**目标：** 把后台接口挂到路由，并引入软删除

**涉及文件：**
- 创建 `internal/router/admin_router.go`
- 修改 `internal/router/router.go`

**关键点：**
- 后台路由组使用两个中间件：`JWTAuth` + `AdminAuth`
- 顺序很重要：先 JWT 校验身份，再校验角色
- 软删除：在 model 中加 `DeletedAt gorm.DeletedAt `gorm:"index"``
- GORM 默认支持软删除，只要在 struct 里有 `DeletedAt` 字段
- 软删除后，前台列表查询会自动过滤已删除记录

**关键代码片段（路由注册）：**

```go
// 后台管理路由（需要管理员身份）
admin := r.Group("/api/v1/admin")
admin.Use(middleware.JWTAuth(authCache, cfg.JWT.Secret))
admin.Use(middleware.AdminAuth())
{
    // 活动管理
    admin.GET("/events", adminHandler.ListEvents)
    admin.POST("/events", adminHandler.CreateEvent)
    admin.PUT("/events/:id", adminHandler.UpdateEvent)
    admin.DELETE("/events/:id", adminHandler.DeleteEvent)
    
    // 资源管理
    admin.GET("/resources", adminHandler.ListResources)
    admin.POST("/resources", adminHandler.CreateResource)
    admin.PUT("/resources/:id", adminHandler.UpdateResource)
    admin.DELETE("/resources/:id", adminHandler.DeleteResource)
    
    // 资讯管理
    admin.GET("/news", adminHandler.ListNews)
    admin.POST("/news", adminHandler.CreateNews)
    admin.PUT("/news/:id", adminHandler.UpdateNews)
    admin.DELETE("/news/:id", adminHandler.DeleteNews)
    
    // 作品档案管理
    admin.GET("/showcases", adminHandler.ListShowcases)
    admin.POST("/showcases", adminHandler.CreateShowcase)
    admin.PUT("/showcases/:id", adminHandler.UpdateShowcase)
    admin.DELETE("/showcases/:id", adminHandler.DeleteShowcase)
}
```

**关键代码片段（软删除模型改造）：**

```go
import "gorm.io/gorm"

type Event struct {
    // ... 原有字段 ...
    DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`  // json:"-" 避免返回给前端
}
```

**预期效果：**
- 普通用户 token 访问 `/api/v1/admin/events` → 403
- 管理员 token 访问 → 正常执行 CRUD
- 删除后数据库记录还在，`deleted_at` 字段有值
- 前台列表查不到已删除记录

## Step 05：测试后台完整 CRUD 流程

**目标：** 验证从创建到展示的全链路

**验证步骤：**

```bash
# 1. 管理员登录获取 token
ADMIN_TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/admin/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"123456"}' | jq -r '.data.token')

# 2. 创建活动
curl -X POST -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title":"数学建模讲座",
    "summary":"介绍数学建模基础知识",
    "content":"详细内容...",
    "category":"讲座",
    "location":"教学楼A101",
    "start_time":"2026-06-01T14:00:00+08:00",
    "status":1,
    "is_featured":true
  }' \
  http://localhost:8080/api/v1/admin/events

# 3. 前台查看活动列表（应该能看到新创建的活动）
curl http://localhost:8080/api/v1/events

# 4. 查看首页聚合（ featured_events 应该包含新活动）
curl http://localhost:8080/api/v1/home

# 5. 修改活动
curl -X PUT -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"数学建模讲座（更新版）"}' \
  http://localhost:8080/api/v1/admin/events/1

# 6. 删除活动
curl -X DELETE -H "Authorization: Bearer $ADMIN_TOKEN" \
  http://localhost:8080/api/v1/admin/events/1

# 7. 确认前台列表已无此活动
curl http://localhost:8080/api/v1/events
```

**预期效果：**
- 创建后前台能立即看到
- 修改后前台显示更新内容
- 删除后前台不再显示（但数据库中 `deleted_at` 有值）

## Step 06：添加后台统计接口（可选）

**目标：** 为后台仪表盘提供基础统计数据

**涉及文件：**
- 修改 `internal/service/admin_service.go`
- 修改 `internal/handler/admin_handler.go`

**关键点：**
- 统计内容总数：活动数、资源数、资讯数、作品数
- 统计用户数、收藏数
- 可按状态分组统计（草稿 vs 已发布）
- 第一版可用简单的 `db.Model(&model.Event{}).Count(&count)`

**关键代码片段：**

```go
func (s *AdminService) GetDashboardStats() (*dto.DashboardStats, error) {
    var stats dto.DashboardStats
    
    s.db.Model(&model.Event{}).Where("status = ?", 1).Count(&stats.EventCount)
    s.db.Model(&model.Resource{}).Where("status = ?", 1).Count(&stats.ResourceCount)
    s.db.Model(&model.News{}).Where("status = ?", 1).Count(&stats.NewsCount)
    s.db.Model(&model.Showcase{}).Where("status = ?", 1).Count(&stats.ShowcaseCount)
    s.db.Model(&model.User{}).Count(&stats.UserCount)
    
    return &stats, nil
}
```

**预期效果：**
```bash
curl -H "Authorization: Bearer $ADMIN_TOKEN" \
  http://localhost:8080/api/v1/admin/dashboard/stats
# 返回：{ event_count, resource_count, news_count, showcase_count, user_count }
```
