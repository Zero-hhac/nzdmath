## Step 02：会员资料

**文件**：`internal/service/member_service.go`

获取资料很简单，直接按 `user_id` 查 `users` 表：

```go
func (s *MemberService) GetProfile(userID uint) (*model.User, error) {
	var user model.User
	if err := s.db.First(&user, userID).Error; err != nil {
		return nil, errors.New("用户不存在")
	}
	return &user, nil
}
```

更新资料**只允许改白名单字段**（nickname / avatar / bio / email），用 map 显式指定：

```go
func (s *MemberService) UpdateProfile(userID uint, nickname string, avatar string, bio string, email string) error {
	updates := map[string]interface{}{
		"nickname": nickname,
		"avatar":   avatar,
		"bio":      bio,
	}
	if email == "" {
		updates["email"] = nil
	} else {
		updates["email"] = email
	}
	return s.db.Model(&model.User{}).Where("id = ?", userID).Updates(updates).Error
}
```

**关键点**：
- `user_id` 从 gin Context 拿（JWT 中间件写入），不信任前端传值
- `username`、`role`、`status`、`password_hash` 都不在更新白名单里，前端传了也改不了
- email 传空字符串会置为 `nil`（清空）

**验证**：

```bash
curl -H "Authorization: Bearer <token>" http://localhost:8080/api/v1/profile
curl -X PUT -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"新昵称","bio":"数学爱好者"}' \
  http://localhost:8080/api/v1/profile
```

## Step 03：头像上传

**文件**：`internal/service/avatar_service.go`

头像限制 5MB、只允许图片格式，按「年/月」分目录存储，文件名带用户 ID 和时间戳：

```go
func (s *AvatarService) Upload(userID uint, file *multipart.FileHeader) (string, error) {
	if file.Size > 5*1024*1024 {
		return "", errors.New("头像文件不能超过 5MB")
	}
	ext := strings.ToLower(filepath.Ext(file.Filename))
	if !allowedImageExts[ext] { // jpg/jpeg/png/gif/webp
		return "", errors.New("只支持 jpg/jpeg/png/gif/webp 格式")
	}

	uploadBase := config.GlobalConfig.Storage.UploadDir
	if uploadBase == "" {
		uploadBase = "./storage/uploads"
	}
	now := time.Now()
	dir := filepath.Join(uploadBase, "avatars", now.Format("2006"), now.Format("01"))
	if err := os.MkdirAll(dir, 0775); err != nil {
		return "", fmt.Errorf("创建目录失败: %v", err)
	}

	filename := fmt.Sprintf("u%d_%d%s", userID, now.UnixNano(), ext)
	savePath := filepath.Join(dir, filename)
	// ... 打开源文件、创建目标文件、io 拷贝 ...

	url := fmt.Sprintf("/uploads/avatars/%s/%s/%s", now.Format("2006"), now.Format("01"), filename)
	if err := s.db.Model(&model.User{}).Where("id = ?", userID).Update("avatar", url).Error; err != nil {
		return "", errors.New("更新头像失败")
	}
	return url, nil
}
```

**关键点**：
- 存到磁盘的是物理路径，返回给前端、写入 DB 的是 `/uploads/avatars/...` URL
- 上传成功后同步更新 `users.avatar` 字段

## Step 04：收藏

**文件**：`internal/service/favorite_service.go`

收藏支持四种目标类型（event/news/resource/showcase）。添加时直接建记录：

```go
func (s *FavoriteService) AddFavorite(userID uint, targetID uint, targetType string) error {
	fav := model.Favorite{
		UserID:     userID,
		TargetType: targetType,
		TargetID:   targetID,
	}
	return s.db.Create(&fav).Error
}
```

删除时校验「只能删自己的收藏」：

```go
func (s *FavoriteService) RemoveFavorite(favoriteID uint, userID uint) error {
	var fav model.Favorite
	err := s.db.First(&fav, favoriteID).Error
	if err != nil {
		return errors.New("收藏记录不存在")
	}
	if fav.UserID != userID {
		return errors.New("无权删除他人收藏记录")
	}
	return s.db.Delete(&fav).Error
}
```

## Step 06：聊天室

**文件**：`internal/service/chat_service.go`

聊天室是项目里最复杂的模块，混合了 MySQL 持久化 + Redis 排序集合做增量推送。

**消息类型**：

```go
const (
	ChatMessageTypeText   = "text"
	ChatMessageTypeImage  = "image"
	ChatMessageTypeFile   = "file"
	ChatMessageTypeSystem = "system"

	ChatMaxFileSize  = 5 * 1024 * 1024
	chatOnlineTTL    = 30 * time.Second
	chatRecallWindow = 2 * time.Minute  // 撤回窗口
)
```

**核心机制**：
- **在线状态**：`chat_presences` 表存持久状态，Redis 的 `chat:presence` 有序集合（score=时间戳）做实时在线计数，30 秒无心跳视为离线
- **消息流**：新消息写 MySQL 后，同步塞进 Redis `chat:stream` 有序集合（score=消息 ID），容量上限 2000 条
- **增量拉取**：客户端带 `after_id` 轮询，优先从 Redis 流读，miss 则回退数据库
- **撤回**：用户只能撤回自己 2 分钟内的消息；撤回后写 `chat:deleted` 集合，其他客户端据此移除本地消息

加入聊天室（`Join`）会判断是否首次进入，是则广播一条系统消息「xxx 加入聊天室」：

```go
func (s *ChatService) Join(userID uint) (int64, error) {

	return s.OnlineCount()

```
