## Step 01：实现会员资料接口

**目标：** 让登录用户能查看和修改自己的资料

**涉及文件：**
- 创建 `internal/dto/member_dto.go`
- 创建 `internal/repository/member_repository.go`
- 创建 `internal/service/member_service.go`
- 创建 `internal/handler/member_handler.go`
- 创建 `internal/router/member_router.go`

**关键点：**
- `GET /api/v1/profile`：从 gin context 取 `user_id`，查 users 表
- `PUT /api/v1/profile`：只允许修改 nickname、avatar、bio
- **禁止**前端修改：username、role、status、password_hash
- 更新时只更新允许字段，其他字段忽略

**关键代码片段（ProfileHandler）：**

```go
func (h *MemberHandler) GetProfile(c *gin.Context) {
    userID, exists := c.Get("user_id")
    if !exists {
        response.Error(c, 401, "未登录")
        return
    }
    
    user, err := h.memberService.GetProfile(userID.(uint))
    if err != nil {
        response.Error(c, 500, "获取资料失败")
        return
    }
    
    response.Success(c, user)
}

func (h *MemberHandler) UpdateProfile(c *gin.Context) {
    userID := c.GetUint("user_id")
    
    var req dto.UpdateProfileRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        response.Error(c, 400, err.Error())
        return
    }
    
    if err := h.memberService.UpdateProfile(userID, req); err != nil {
        response.Error(c, 500, "更新失败")
        return
    }
    
    response.Success(c, nil)
}
```

**关键代码片段（UpdateProfileRequest DTO）：**

```go
type UpdateProfileRequest struct {
    Nickname string `json:"nickname" binding:"max=50"`
    Avatar   string `json:"avatar" binding:"max=500"`
    Bio      string `json:"bio" binding:"max=1000"`
}
```

**预期效果：**
```bash
# 获取当前用户资料（需登录）
curl -H "Authorization: Bearer <token>" http://localhost:8080/api/v1/profile

# 更新资料（只能改 nickname/avatar/bio）
curl -X PUT -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"新昵称","bio":"数学爱好者"}' \
  http://localhost:8080/api/v1/profile
```

## Step 02：实现收藏功能（创建 + 删除）

**目标：** 让用户能收藏/取消收藏活动、资源、资讯、作品

**涉及文件：**
- 创建 `internal/dto/favorite_dto.go`
- 创建 `internal/repository/favorite_repository.go`
- 创建 `internal/service/favorite_service.go`
- 创建 `internal/handler/favorite_handler.go`

**关键点：**
- 收藏请求：`{ "target_type": "resource", "target_id": 12 }`
- `target_type` 只允许：`event`、`resource`、`news`、`showcase`
- 收藏前先校验目标内容是否存在（查对应表）
- 数据库加唯一索引：`user_id + target_type + target_id`（防止重复收藏）
- 删除时只需传收藏记录 ID，或传 `target_type + target_id` 组合

**关键代码片段（CreateFavorite）：**

```go
func (s *FavoriteService) CreateFavorite(userID uint, req dto.CreateFavoriteRequest) error {
    // 校验 target_type 合法性
    allowed := map[string]bool{"event": true, "resource": true, "news": true, "showcase": true}
    if !allowed[req.TargetType] {
        return errors.New("非法的收藏类型")
    }
    
    // 校验目标是否存在
    exists, err := s.checkTargetExists(req.TargetType, req.TargetID)
    if err != nil || !exists {
        return errors.New("收藏内容不存在")
    }
    
    // 创建收藏记录
    favorite := model.Favorite{
        UserID:     userID,
        TargetType: req.TargetType,
        TargetID:   req.TargetID,
    }
    return s.favoriteRepo.Create(&favorite)
}
```

**预期效果：**
```bash
# 收藏一个资源
curl -X POST -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"target_type":"resource","target_id":1}' \
  http://localhost:8080/api/v1/member/favorites

# 取消收藏（传收藏记录ID）
curl -X DELETE -H "Authorization: Bearer <token>" \
  http://localhost:8080/api/v1/member/favorites/1
```

**关键点：**
- 查 favorites 表得到 `target_type + target_id` 列表
- 根据 type 分别查 events/resources/news/showcases 表
- 组装成统一的响应结构返回
- 考虑分页（收藏可能很多）

**关键代码片段（展开查询）：**

```go
func (s *FavoriteService) ListFavorites(userID uint, page, pageSize int) ([]dto.FavoriteItem, int64, error) {
    favorites, total, err := s.favoriteRepo.ListByUser(userID, page, pageSize)
    if err != nil {
        return nil, 0, err
    }
    
    var items []dto.FavoriteItem
    for _, fav := range favorites {
        item := dto.FavoriteItem{
            ID:         fav.ID,
            TargetType: fav.TargetType,
            TargetID:   fav.TargetID,
            CreatedAt:  fav.CreatedAt,
        }
        
        // 根据类型查详情
        switch fav.TargetType {
        case "event":
            event, _ := s.eventRepo.FindByID(fav.TargetID)
            if event != nil {
                item.Title = event.Title
                item.CoverURL = event.CoverURL
            }
        case "resource":
            // ...
        // ... 其他类型
        }
        
        items = append(items, item)
    }
    
    return items, total, nil
}
```

**预期效果：**
```bash
curl -H "Authorization: Bearer <token>" \
  "http://localhost:8080/api/v1/member/favorites?page=1&page_size=10"
# 返回：[{ id, target_type, target_id, title, cover_url, created_at }]
```

- 点赞数第一版可先展示，不做真实点赞接口（后续扩展）
- 作品字段多（author_name、field、award、competition 等），确保 DTO 覆盖

**关键代码片段（浏览量自增）：**

```go
func (s *ShowcaseService) GetDetail(id uint) (*model.Showcase, error) {
    showcase, err := s.repo.FindByID(id)
    if err != nil {
        return nil, err
    }
    
    // 异步或同步增加浏览量（第一版可直接同步）
    s.repo.IncrementViews(id)
    
    return showcase, nil
}
```
