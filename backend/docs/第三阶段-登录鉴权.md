# 第三阶段：登录鉴权

本阶段目标：实现用户和管理员登录，使用 JWT 签发 token，Redis 存储登录态，中间件校验身份。

## Step 01：设计登录请求/响应 DTO

**目标：** 明确定义登录接口的输入输出结构

**涉及文件：**
- 创建 `internal/dto/auth_dto.go`

**关键点：**
- `LoginRequest`：username + password
- `LoginResponse`：token + expire_at + user_info
- 区分用户登录和管理员登录的响应（字段可复用）

**关键代码片段：**

```go
package dto

// 通用登录请求
type LoginRequest struct {
    Username string `json:"username" binding:"required,min=3,max=50"`
    Password string `json:"password" binding:"required,min=6,max=100"`
}

// 登录响应
type LoginResponse struct {
    Token    string    `json:"token"`
    ExpireAt string    `json:"expire_at"`
    UserInfo UserInfo  `json:"user_info"`
}

type UserInfo struct {
    ID       uint   `json:"id"`
    Username string `json:"username"`
    Nickname string `json:"nickname"`
    Role     string `json:"role"`
}
```

**预期效果：**
编译通过，binding tag 能被 gin 的 validator 识别。

## Step 02：设计 Redis key 和缓存封装

**目标：** 统一管理 Redis key，封装 token 存取逻辑

**涉及文件：**
- 创建 `internal/cache/keys.go`
- 创建 `internal/cache/auth_cache.go`

**关键点：**
- key 格式：`login:token:{token}`
- value 存用户 id + role + username（可用 JSON 或 `:` 分隔）
- 过期时间与 JWT 保持一致（如 24 小时）
- 提供 `SetToken`、`GetToken`、`DelToken` 三个方法

**关键代码片段（keys.go）：**

```go
package cache

func KeyAuthToken(token string) string {
    return "login:token:" + token
}
```

**关键代码片段（auth_cache.go）：**

```go
package cache

type AuthCache struct {
    rdb *redis.Client
}

func NewAuthCache(rdb *redis.Client) *AuthCache {
    return &AuthCache{rdb: rdb}
}

func (c *AuthCache) SetToken(token string, userID uint, role string, expire time.Duration) error {
    key := KeyAuthToken(token)
    value := fmt.Sprintf("%d:%s", userID, role)
    return c.rdb.Set(context.Background(), key, value, expire).Err()
}

func (c *AuthCache) GetToken(token string) (userID uint, role string, err error) {
    key := KeyAuthToken(token)
    val, err := c.rdb.Get(context.Background(), key).Result()
    if err != nil {
        return 0, "", err
    }
    // 解析 "userID:role"
    // ...
    return userID, role, nil
}
```

**预期效果：**
`cache/auth_cache.go` 编译通过，能用 `SetToken` 写入、用 `GetToken` 读取。

**如果出错：**
- Redis client 未传入，检查 NewAuthCache 的初始化位置
- context 未导入

**关键代码片段：**

```go
package repository

import (
    "math-top-backend/internal/model"
    "gorm.io/gorm"
)

type UserRepository struct {
    db *gorm.DB
}

func NewUserRepository(db *gorm.DB) *UserRepository {
    return &UserRepository{db: db}
}

func (r *UserRepository) FindByUsername(username string) (*model.User, error) {
    var user model.User

        return nil, err
    }
    return &user, nil
}
```

**预期效果：**

## Step 04：编写登录服务层

**目标：** 实现登录的核心业务逻辑：校验密码 → 签发 JWT → 写入 Redis

**涉及文件：**
- 创建 `internal/service/auth_service.go`

**关键点：**
- 密码校验用 `golang.org/x/crypto/bcrypt.CompareHashAndPassword`
- JWT 签发用 `github.com/golang-jwt/jwt/v5`
- Claims 中只放：`user_id`、`role`、`username`、`exp`
- 登录成功后写入 Redis

**关键代码片段：**

```go
func (s *AuthService) Login(req dto.LoginRequest) (*dto.LoginResponse, error) {
    // 1. 查用户
    user, err := s.userRepo.FindByUsername(req.Username)
    if err != nil {
        return nil, errors.New("用户不存在")
    }
    
    // 2. 校验密码
    if err := bcrypt.CompareHashAndPassword([]byte(user.PasswordHash), []byte(req.Password)); err != nil {
        return nil, errors.New("密码错误")
    }
    
    // 3. 生成 JWT
    token, expireAt, err := s.generateToken(user.ID, user.Username, user.Role)
    if err != nil {
        return nil, err
    }
    
    // 4. 写入 Redis
    if err := s.authCache.SetToken(token, user.ID, user.Role, s.jwtExpire); err != nil {
        return nil, err
    }
    
    return &dto.LoginResponse{
        Token:    token,
        ExpireAt: expireAt.Format(time.RFC3339),
        UserInfo: dto.UserInfo{ID: user.ID, Username: user.Username, Nickname: user.Nickname, Role: user.Role},
    }, nil
}
```

**预期效果：**
输入正确的用户名密码，返回 token；输入错误的密码，返回 "密码错误"。

**如果出错：**
- bcrypt 版本不对：`go get golang.org/x/crypto/bcrypt`
- JWT claims 类型错误：注意用 `jwt.MapClaims` 或自定义 struct

## Step 05：编写登录 Handler

**目标：** 暴露 HTTP 登录接口

**涉及文件：**
- 创建 `internal/handler/auth_handler.go`

**关键点：**
- `POST /api/v1/auth/login` — 用户登录
- `POST /api/v1/admin/login` — 管理员登录
- 用 `c.ShouldBindJSON(&req)` 解析请求
- 错误返回 400（参数错误）或 401（认证失败）

**关键代码片段：**

```go
func (h *AuthHandler) UserLogin(c *gin.Context) {
    var req dto.LoginRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        response.Error(c, 400, "请求参数错误: "+err.Error())
        return
    }
    
    resp, err := h.authService.Login(req)
    if err != nil {
        response.Error(c, 401, err.Error())
        return
    }
    
    response.Success(c, resp)
}
```

**预期效果：**
```bash
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}'
# 返回：{"code":0,"message":"success","data":{"token":"xxx","expire_at":"...","user_info":{...}}}
```

## Step 06：编写 JWT 校验中间件

**目标：** 校验请求头中的 token，把用户信息写入 gin Context

**涉及文件：**
- 创建 `internal/middleware/jwt.go`

**关键点：**
- 从 `Authorization: Bearer <token>` 头中提取 token
- 解析 JWT 签名和过期时间
- 查 Redis 确认 token 仍然有效（未被注销）
- 把 `user_id`、`role`、`username` 写入 `c.Set("user_id", ...)`
- 后续 handler 用 `c.GetUint("user_id")` 获取

**关键代码片段：**

```go
func JWTAuth(authCache *cache.AuthCache, secret string) gin.HandlerFunc {
    return func(c *gin.Context) {
        authHeader := c.GetHeader("Authorization")
        if authHeader == "" {
            response.Error(c, 401, "缺少 Authorization 头")
            c.Abort()
            return
        }
        
        // 提取 Bearer 后的 token
        parts := strings.SplitN(authHeader, " ", 2)
        if len(parts) != 2 || parts[0] != "Bearer" {
            response.Error(c, 401, "Authorization 格式错误")
            c.Abort()
            return
        }
        tokenString := parts[1]
        
        // 解析 JWT
        token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
            return []byte(secret), nil
        })
        if err != nil || !token.Valid {
            response.Error(c, 401, "token 无效或已过期")
            c.Abort()
            return
        }
        
        // 查 Redis
        userID, role, err := authCache.GetToken(tokenString)
        if err != nil {
            response.Error(c, 401, "token 已失效")
            c.Abort()
            return
        }
        
        // 写入上下文
        c.Set("user_id", userID)
        c.Set("role", role)
        c.Next()
    }
}
```

**预期效果：**
- 带正确 token 的请求能进入后续 handler
- 不带 token 或 token 错误的请求返回 401

## Step 07：编写管理员权限中间件

**目标：** 在 JWT 校验后，再确认角色是 admin

**涉及文件：**
- 创建 `internal/middleware/admin_auth.go`

**关键点：**
- 依赖 JWT 中间件先执行（即先调用 `JWTAuth`）
- 从 context 中读取 `role`
- `role != "admin"` 时返回 403

**关键代码片段：**

```go
func AdminAuth() gin.HandlerFunc {
    return func(c *gin.Context) {
        role, exists := c.Get("role")
        if !exists || role != "admin" {
            response.Error(c, 403, "无管理员权限")
            c.Abort()
            return
        }
        c.Next()
    }
}
```

**预期效果：**
- 普通用户 token 访问 admin 接口 → 403
- 管理员 token 访问 admin 接口 → 正常通过

## Step 08：注册鉴权路由 + 准备测试用户

**目标：** 把登录接口和受保护接口注册到路由，并插入测试用户

**涉及文件：**
- 创建 `internal/router/auth_router.go`
- 修改 `internal/router/router.go`

**关键点：**
- 公开路由组：不需要中间件
- 用户路由组：需要 `JWTAuth`
- 管理员路由组：需要 `JWTAuth` + `AdminAuth`
- 先在数据库中手工插入测试用户（第一版不用做注册接口）

**路由注册示例：**

```go
// 公开路由
public := r.Group("/api/v1")
{
    public.POST("/auth/login", authHandler.UserLogin)
    public.POST("/admin/login", authHandler.AdminLogin)
}

// 用户路由（需要登录）
userGroup := r.Group("/api/v1")
userGroup.Use(middleware.JWTAuth(authCache, cfg.JWT.Secret))
{
    userGroup.GET("/profile", memberHandler.GetProfile)
}

// 管理员路由
adminGroup := r.Group("/api/v1/admin")
adminGroup.Use(middleware.JWTAuth(authCache, cfg.JWT.Secret))
adminGroup.Use(middleware.AdminAuth())
{
    adminGroup.GET("/events", adminHandler.ListEvents)
}
```

**插入测试用户（SQL）：**

```sql
-- 密码是 "123456" 的 bcrypt 哈希（每次生成不同，以下仅示例）
INSERT INTO users (username, password_hash, nickname, role, status) 
VALUES ('testuser', '$2a$10$xxxxxxxx', '测试用户', 'member', 1);

INSERT INTO admins (username, password_hash, nickname, status) 
VALUES ('admin', '$2a$10$xxxxxxxx', '管理员', 1);
```

> 提示：你可以先用 Go 代码生成一个 bcrypt hash，然后复制到 SQL 中：
> ```go
> hash, _ := bcrypt.GenerateFromPassword([]byte("123456"), bcrypt.DefaultCost)
> fmt.Println(string(hash))
> ```

**预期效果：**
- 用户登录返回 token
- Redis 中出现 `login:token:xxx` 的 key
- 无 token 访问 `/api/v1/profile` → 401
- 用户 token 访问 `/api/v1/admin/events` → 403
- 管理员 token 访问 `/api/v1/admin/events` → 200
