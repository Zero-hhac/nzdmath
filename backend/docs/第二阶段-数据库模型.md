## Step 01：建立用户模型

**目标：** 创建 `users` 表，支撑会员登录和个人资料

**涉及文件：**
- 创建 `internal/model/user.go`

**关键点：**
- 字段：`ID, Username, PasswordHash, Nickname, Email, Avatar, Bio, Role, Status, CreatedAt, UpdatedAt`
- `PasswordHash` 存 bcrypt 加密后的值，不存明文
- `Role` 用 string（如 `"member"`、`"admin"`），不要用 bool
- `Status` 用 int（0=禁用，1=正常）

**关键代码片段：**

```go
type User struct {
    ID           uint      `gorm:"primarykey" json:"id"`
    Username     string    `gorm:"size:50;not null;uniqueIndex" json:"username"`
    PasswordHash string    `gorm:"size:255;not null" json:"-"`  // json:"-" 避免返回给前端
    Nickname     string    `gorm:"size:50" json:"nickname"`
    Email        string    `gorm:"size:100" json:"email"`
    Avatar       string    `gorm:"size:255" json:"avatar"`
    Bio          string    `gorm:"type:text" json:"bio"`
    Role         string    `gorm:"size:20;default:member" json:"role"`
    Status       int       `gorm:"default:1" json:"status"`
    CreatedAt    time.Time `json:"created_at"`
    UpdatedAt    time.Time `json:"updated_at"`
}

func (User) TableName() string {
    return "users"
}
```

**预期效果：**
编译通过，User struct 能正确序列化 JSON（不含 PasswordHash）。

**如果出错：**
- `json:"-"` 写法错误，应为短横线不是下划线
- `time.Time` 需要导入 `time` 包

## Step 02：建立管理员模型

**目标：** 创建 `admins` 表，支撑后台管理登录

**涉及文件：**
- 创建 `internal/model/admin.go`

**关键点：**
- 字段与 User 类似但更精简：`ID, Username, PasswordHash, Nickname, Email, Status, CreatedAt, UpdatedAt`
- 也可以复用 users 表加 Role 字段，但第一版分开更直观
- 不要混淆 `users` 和 `admins`，后台接口只查 admins 表

**关键代码片段：**

```go
type Admin struct {
    ID           uint      `gorm:"primarykey" json:"id"`
    Username     string    `gorm:"size:50;not null;uniqueIndex" json:"username"`
    PasswordHash string    `gorm:"size:255;not null" json:"-"`
    Nickname     string    `gorm:"size:50" json:"nickname"`
    Email        string    `gorm:"size:100" json:"email"`
    Status       int       `gorm:"default:1" json:"status"`
    CreatedAt    time.Time `json:"created_at"`
    UpdatedAt    time.Time `json:"updated_at"`
}

func (Admin) TableName() string {
    return "admins"
}
```

**预期效果：**
与 User 模型结构相似，编译通过。

## Step 03：建立活动模型

**目标：** 创建 `events` 表，支撑活动中心页面

**涉及文件：**
- 创建 `internal/model/event.go`

**关键点：**
- 字段要覆盖前端需求：标题、摘要、正文、分类、地点、时间、封面、推荐标记
- `StartTime` / `EndTime` 用 `*time.Time`（指针），允许为空
- `IsFeatured` 标记是否首页推荐
- `Status` 控制是否显示

**关键代码片段：**

```go
type Event struct {
    ID          uint       `gorm:"primarykey" json:"id"`
    Title       string     `gorm:"size:200;not null" json:"title"`
    Summary     string     `gorm:"type:text" json:"summary"`
    Content     string     `gorm:"type:longtext" json:"content"`
    Category    string     `gorm:"size:50" json:"category"`
    Location    string     `gorm:"size:200" json:"location"`
    StartTime   *time.Time `json:"start_time"`
    EndTime     *time.Time `json:"end_time"`
    CoverURL    string     `gorm:"size:500" json:"cover_url"`
    Status      int        `gorm:"default:1" json:"status"`
    IsFeatured  bool       `gorm:"default:false" json:"is_featured"`
    CreatedBy   uint       `json:"created_by"`
    CreatedAt   time.Time  `json:"created_at"`
    UpdatedAt   time.Time  `json:"updated_at"`
}
```

**预期效果：**
Event struct 包含前端活动中心需要的全部字段。

**如果出错：**
- `time.Time` 在 JSON 序列化时格式不对，确保 `parseTime=True` 在 DSN 中
- `*time.Time` 为空时 JSON 会是 `null`，前端要处理

## Step 04：建立资源、资讯、作品档案模型

**目标：** 批量创建其余 4 张表

**涉及文件：**
- 创建 `internal/model/resource.go`（资源存档）
- 创建 `internal/model/news.go`（动态资讯）
- 创建 `internal/model/showcase.go`（作品档案馆）
- 创建 `internal/model/favorite.go`（收藏关系）

**关键点：**
- `Resource`：关注 `Type`（文件类型）、`Format`（格式）、`FileURL`、`DownloadCount`
- `News`：关注 `PublishedAt`（发布日期）、`Tag`
- `Showcase`：关注 `Field`（领域）、`Award`（奖项）、`Competition`、`LikesCount`、`ViewsCount`
- `Favorite`：关注 `TargetType` + `TargetID` 的组合键，避免重复收藏

**关键代码片段（Showcase）：**

```go
type Showcase struct {
    ID          uint      `gorm:"primarykey" json:"id"`
    Title       string    `gorm:"size:200;not null" json:"title"`
    AuthorName  string    `gorm:"size:100" json:"author_name"`
    Field       string    `gorm:"size:100" json:"field"`
    Type        string    `gorm:"size:50" json:"type"`
    Award       string    `gorm:"size:200" json:"award"`
    Summary     string    `gorm:"type:text" json:"summary"`
    Content     string    `gorm:"type:longtext" json:"content"`
    ImageURL    string    `gorm:"size:500" json:"image_url"`
    Competition string    `gorm:"size:200" json:"competition"`
    LikesCount  int       `gorm:"default:0" json:"likes_count"`
    ViewsCount  int       `gorm:"default:0" json:"views_count"`
    Status      int       `gorm:"default:1" json:"status"`
    IsFeatured  bool      `gorm:"default:false" json:"is_featured"`
    CreatedBy   uint      `json:"created_by"`
    CreatedAt   time.Time `json:"created_at"`
    UpdatedAt   time.Time `json:"updated_at"`
}
```

**关键代码片段（Favorite）：**

```go
type Favorite struct {
    ID         uint      `gorm:"primarykey" json:"id"`
    UserID     uint      `gorm:"not null;index" json:"user_id"`
    TargetType string    `gorm:"size:50;not null" json:"target_type"`  // event/resource/showcase/news
    TargetID   uint      `gorm:"not null" json:"target_id"`
    CreatedAt  time.Time `json:"created_at"`
}

// 唯一索引：一个用户对同一内容只能收藏一次
func (Favorite) TableName() string {
    return "favorites"
}
```

**预期效果：**
4 个模型文件都编译通过。

## Step 05：配置自动建表

**目标：** 服务启动时自动创建所有表

**涉及文件：**
- 修改 `internal/bootstrap/db.go`

**关键点：**
- 在 `InitDB` 函数末尾添加 `db.AutoMigrate(...)`
- 传入所有模型：`&model.User{}, &model.Admin{}, &model.Event{}, ...`
- AutoMigrate 是增量的，不会删除已有数据

**关键代码片段：**

```go
import "math-top-backend/internal/model"

func InitDB(cfg *config.Config) *gorm.DB {
    // ... 连接代码 ...
    
    err = db.AutoMigrate(
        &model.User{},
        &model.Admin{},
        &model.Event{},
        &model.Resource{},
        &model.News{},
        &model.Showcase{},
        &model.Favorite{},
    )
    if err != nil {
        log.Fatalf("自动建表失败: %v", err)
    }
    log.Println("数据库表已自动创建/更新")
    
    return db
}
```

**预期效果：**
启动后终端显示 "数据库表已自动创建/更新"。

**如果出错：**
- 模型中有语法错误（如未导入包）
- MySQL 权限不足，无法 CREATE TABLE
- 字段类型与 MySQL 版本不兼容（如 `longtext` 在老版本）
