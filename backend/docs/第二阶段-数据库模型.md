# 第二阶段：数据库模型

本阶段目标：理解 13 张表的 GORM 模型设计与字段约束，掌握软删除、唯一索引、表名的约定。

> 对应代码：`internal/model/` 下的所有模型文件，建表入口在 `internal/router/router.go` 的 `AutoMigrate`

---

## Step 01：模型总览

项目在 `internal/model/` 下定义了 13 个模型，启动时通过 `db.AutoMigrate(...)` 一次性自动建表（增量式，不会删除已有数据或字段）。

| 模型文件 | 表名 | 核心字段 |
|---|---|---|
| `user.go` | `users` | Username(唯一)、PasswordHash、Role、Status、LastLoginAt |
| `admin.go` | `admins` | Username(唯一)、PasswordHash、Role |
| `event.go` | `events` | Title、StartTime、EndTime、IsFeatured |
| `news.go` | `news` | Title、Tag、PublishedAt、IsFeatured |
| `resource.go` | `resources` | FilePath、DownloadCount、ViewCount、LikeCount |
| `showcase.go` | `showcases` | Author、Field、Competition、H5URL |
| `favorite.go` | `favorites` | UserID、TargetType、TargetID |
| `comment.go` | `comments` / `comment_likes` | TargetType、TargetID、Rating、ParentID |
| `chat.go` | `chat_messages` / `chat_presences` | MessageType、FilePath、IsOnline |
| `download_log.go` | `download_logs` | UserID、ResourceID、IP、UserAgent |
| `daily_metric.go` | `daily_metrics` | Date(唯一)、PV、UV、DAU |

**通用约定**：
- 主键统一 `ID uint` + `gorm:"primaryKey;autoIncrement"`
- 时间字段统一 `CreatedAt` / `UpdatedAt`，GORM 自动维护
- 软删除字段用 `DeletedAt *time.Time \`gorm:"index" json:"-"\``
- 每个模型都实现 `TableName()` 显式指定表名

## Step 02：用户与管理员模型

**文件**：`internal/model/user.go`、`internal/model/admin.go`

```go
type User struct {
	ID           uint       `gorm:"primaryKey;autoIncrement" json:"id"`
	Username     string     `gorm:"type:varchar(50);not null;uniqueIndex" json:"username"`
	PasswordHash string     `gorm:"type:varchar(255);not null" json:"-"`
	Nickname     string     `gorm:"type:varchar(50)" json:"nickname"`
	Email        *string    `gorm:"type:varchar(100);uniqueIndex" json:"email"`
	Avatar       string     `gorm:"type:varchar(500)" json:"avatar"`
	Bio          string     `gorm:"type:text" json:"bio"`
	Role         string     `gorm:"type:varchar(20);default:'member';index" json:"role"`
	Status       int        `gorm:"type:tinyint;default:1;index" json:"status"`
	LastLoginAt  *time.Time `json:"last_login_at"`
	CreatedAt    time.Time  `json:"created_at"`
	UpdatedAt    time.Time  `json:"updated_at"`
	DeletedAt    *time.Time `gorm:"index" json:"-"`
}

func (User) TableName() string { return "users" }
```

**关键点**：
- `PasswordHash` 用 `json:"-"`，永不返回给前端；存 bcrypt 加密结果
- `Email` 是 `*string`（指针），允许为空，且加了唯一索引
- `Role` 默认 `member`，取值见 `consts.RoleMember/RoleAdmin/RoleSuperAdmin`
- `Status` 用 int：`1` 正常、`0` 禁用
- `DeletedAt` 让用户支持软删除——禁用/删除后数据库记录仍保留

管理员模型结构与 User 类似但更精简，默认角色是 `admin`：

```go
type Admin struct {
	ID           uint       `gorm:"primaryKey;autoIncrement" json:"id"`
	Username     string     `gorm:"type:varchar(50);not null;uniqueIndex" json:"username"`
	PasswordHash string     `gorm:"type:varchar(255);not null" json:"-"`
	Nickname     string     `gorm:"type:varchar(50)" json:"nickname"`
	Email        string     `gorm:"type:varchar(100)" json:"email"`
	Role         string     `gorm:"type:varchar(20);default:'admin'" json:"role"`
	Status       int        `gorm:"type:tinyint;default:1" json:"status"`
	LastLoginAt  *time.Time `json:"last_login_at"`
	CreatedAt    time.Time  `json:"created_at"`
	UpdatedAt    time.Time  `json:"updated_at"`
}

func (Admin) TableName() string { return "admins" }
```

> `users` 和 `admins` 分表管理，后台接口只查 `admins` 表，与前台会员隔离。

**文件**：`internal/model/event.go`、`internal/model/news.go`

```go
type Event struct {

	Content    string    `gorm:"type:longtext" json:"content"`

	Status     int       `gorm:"type:tinyint;default:1" json:"status"`
	IsFeatured bool      `gorm:"type:boolean;default:false" json:"is_featured"`
	CreatedBy  uint      `json:"created_by"`
	CreatedAt  time.Time `json:"created_at"`
	UpdatedAt  time.Time `json:"updated_at"`
}

```

```go
type News struct {
	ID          uint       `gorm:"primaryKey;autoIncrement" json:"id"`
	Title       string     `gorm:"type:varchar(200);not null" json:"title"`
	Summary     string     `gorm:"type:text" json:"summary"`
	Content     string     `gorm:"type:longtext" json:"content"`
	Category    string     `gorm:"type:varchar(50)" json:"category"`
	Tag         string     `gorm:"type:varchar(100)" json:"tag"`
	CoverURL    string     `gorm:"type:varchar(500)" json:"cover_url"`
	Status      int        `gorm:"type:tinyint;default:1" json:"status"`
	IsFeatured  bool       `gorm:"type:boolean;default:false" json:"is_featured"`
	PublishedAt *time.Time `json:"published_at"`
	CreatedBy   uint       `json:"created_by"`
	CreatedAt   time.Time  `json:"created_at"`
	UpdatedAt   time.Time  `json:"updated_at"`
}

func (News) TableName() string { return "news" }
```

**关键点**：
- 活动的时间用非空的 `time.Time`（StartTime/EndTime 是必填）
- 资讯的 `PublishedAt` 用 `*time.Time` 允许为空，为空时列表按创建时间排序
- `IsFeatured` 控制是否推荐到首页
- `CreatedBy` 记录后台管理员 ID

## Step 04：资源与作品模型

**文件**：`internal/model/resource.go`、`internal/model/showcase.go`

```go
type Resource struct {
	ID            uint       `gorm:"primaryKey;autoIncrement" json:"id"`
	Title         string     `gorm:"type:varchar(200);not null;index" json:"title"`
	Summary       string     `gorm:"type:varchar(500)" json:"summary"`
	Category      string     `gorm:"type:varchar(50);index" json:"category"`
	FileName      string     `gorm:"type:varchar(255)" json:"file_name"`
	FilePath      string     `gorm:"type:varchar(500)" json:"-"`
	FileSize      int64      `json:"file_size"`
	FileType      string     `gorm:"type:varchar(100)" json:"file_type"`
	FileExt       string     `gorm:"type:varchar(20)" json:"file_ext"`
	CoverURL      string     `gorm:"type:varchar(500)" json:"cover_url"`
	ViewCount     int        `gorm:"type:int;default:0" json:"view_count"`
	DownloadCount int        `gorm:"type:int;default:0" json:"download_count"`
	LikeCount     int        `gorm:"type:int;default:0" json:"like_count"`
	Status        int        `gorm:"type:tinyint;default:1;index" json:"status"`
	IsFeatured    bool       `gorm:"type:boolean;default:false;index" json:"is_featured"`
	CreatedBy     uint       `gorm:"index" json:"created_by"`
	CreatedAt     time.Time  `json:"created_at"`
	UpdatedAt     time.Time  `json:"updated_at"`
	DeletedAt     *time.Time `gorm:"index" json:"-"`
}

func (Resource) TableName() string { return "resources" }
```

**关键点**：
- `FilePath` 用 `json:"-"` 不对外暴露磁盘真实路径，前端拿到的是 `file_name` 和 `/uploads/...` 的 URL
- `DownloadCount` 每次下载自增，`ViewCount` 详情访问自增，`LikeCount` 预留
- 资源支持软删除

作品模型字段是 `Author`（不是 `AuthorName`），并带 `H5URL` 支持在线演示：

```go
type Showcase struct {

	Summary     string    `gorm:"type:text" json:"summary"`
	CoverURL    string    `gorm:"type:varchar(500)" json:"cover_url"`
	H5URL       string    `gorm:"type:varchar(500)" json:"h5_url"`
	ViewCount   int       `gorm:"type:int;default:0" json:"view_count"`
	Status      int       `gorm:"type:tinyint;default:1" json:"status"`
	CreatedAt   time.Time `json:"created_at"`

```

## Step 05：收藏、评论、聊天、下载、指标模型

**文件**：`favorite.go`、`comment.go`、`chat.go`、`download_log.go`、`daily_metric.go`

**收藏关系**：

```go
type Favorite struct {
	ID         uint      `gorm:"primaryKey;autoIncrement" json:"id"`
	UserID     uint      `gorm:"not null;index" json:"user_id"`
	TargetID   uint      `gorm:"not null;index" json:"target_id"`
	TargetType string    `gorm:"type:varchar(50);not null" json:"target_type"`
	CreatedAt  time.Time `json:"created_at"`
	UpdatedAt  time.Time `json:"updated_at"`
}

func (Favorite) TableName() string { return "favorites" }
```

`TargetType` 取值限定为 `event` / `news` / `resource` / `showcase`（见 `consts.go`）。去重在 Service 层校验（查重后入库），而非依赖数据库唯一索引。

**评论与点赞**：

```go
type Comment struct {
	ID         uint       `gorm:"primaryKey;autoIncrement" json:"id"`
	UserID     uint       `gorm:"index;not null" json:"user_id"`
	UserName   string     `gorm:"-" json:"user_name"`    // 非 DB 字段，查询时填充
	UserAvatar string     `gorm:"-" json:"user_avatar"`
	TargetType string     `gorm:"type:varchar(20);index;not null" json:"target_type"`
	TargetID   uint       `gorm:"index;not null" json:"target_id"`
	Content    string     `gorm:"type:text;not null" json:"content"`
	Rating     int        `gorm:"type:tinyint;default:0" json:"rating"`
	ParentID   *uint      `gorm:"index" json:"parent_id"`
	LikeCount  int        `gorm:"type:int;default:0" json:"like_count"`
	ReplyCount int        `gorm:"type:int;default:0" json:"reply_count"`
	Status     int        `gorm:"type:tinyint;default:1;index" json:"status"`
	CreatedAt  time.Time  `json:"created_at"`
	UpdatedAt  time.Time  `json:"updated_at"`
	DeletedAt  *time.Time `gorm:"index" json:"-"`
}

type CommentLike struct {
	ID        uint      `gorm:"primaryKey;autoIncrement" json:"id"`
	UserID    uint      `gorm:"index;not null;uniqueIndex:idx_user_comment" json:"user_id"`
	CommentID uint      `gorm:"index;not null;uniqueIndex:idx_user_comment" json:"comment_id"`
	CreatedAt time.Time `json:"created_at"`
}
```

**关键点**：
- `Comment.UserName` / `UserAvatar` 用 `gorm:"-"` 标记为非数据库字段，查询时 JOIN users 表后回填，避免冗余
- `CommentLike` 用 `uniqueIndex:idx_user_comment` 建立「用户+评论」复合唯一索引，防止重复点赞
- `ParentID` 支持楼中楼回复，`Rating` 支持评分

## Step 06：自动建表与验证

建表入口在 `internal/router/router.go` 的 `NewEngine()` 中：

```go
db := config.ConnectMysql()
rdb := config.InitRedis()

if err := db.AutoMigrate(
	&model.User{}, &model.Event{}, &model.News{}, &model.Resource{},
	&model.Favorite{}, &model.Showcase{}, &model.Admin{},
	&model.DownloadLog{}, &model.Comment{}, &model.CommentLike{},
	&model.ChatMessage{}, &model.ChatPresence{}, &model.DailyMetric{},
); err != nil {
	slog.Error("数据库迁移失败", "err", err)
	panic(err)
}
```

**验证方法**：

```bash
mysql -u root -p math_top
SHOW TABLES;
# 应看到 13 张表：users / admins / events / news / resources / showcases /
#   favorites / comments / comment_likes / chat_messages / chat_presences /
#   download_logs / daily_metrics
```

**如果出错**：
- 模型有语法错误（如未导入 `time` 包）
- MySQL 权限不足无法 `CREATE TABLE`
- `longtext`/`tinyint` 等类型在极老版本 MySQL 不兼容
