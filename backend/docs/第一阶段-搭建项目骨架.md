# 第一阶段：搭建项目骨架

本阶段目标：让 Go 后端服务真正跑起来，能连上 MySQL 和 Redis，提供统一响应格式和健康检查接口。

> **参考文档**：`开发文档/01-项目初始化与目录规范.md`、`开发文档/02-配置管理与基础启动.md`

---

## Step 01：检查并安装依赖

**目标：** 确保 `go.mod` 中有所有需要的依赖

**涉及文件：**
- 修改 `go.mod`（可选，如果已有则跳过）

**关键点：**
- 当前 `go.mod` 已有 gin、go-yaml、crypto 等，但可能缺少：gorm、mysql-driver、go-redis、viper、jwt

**安装命令（按需执行）：**

```bash
go get github.com/gin-gonic/gin
go get gorm.io/gorm
go get gorm.io/driver/mysql
go get github.com/redis/go-redis/v9
go get github.com/spf13/viper
go get github.com/golang-jwt/jwt/v5
go get golang.org/x/crypto/bcrypt  # 后续鉴权阶段用
```

**预期效果：**
执行 `go mod tidy` 后无报错，`go.mod` 中出现以上依赖。

**如果出错：**
- 检查 Go 版本是否 >= 1.22
- 尝试 `go mod download` 或设置国内代理：`go env -w GOPROXY=https://goproxy.cn,direct`

## Step 02：编写配置文件

**目标：** 让后端知道数据库、Redis、JWT 密钥等信息

**涉及文件：**
- 创建/修改 `configs/config.example.yaml`（模板，不含真实密码）
- 创建/修改 `configs/config.yaml`（你的本地开发配置）

**关键点：**
- 不要把真实密码提交到 Git，所以 `config.yaml` 要加 `.gitignore`
- `config.example.yaml` 只放占位符

**关键代码片段（configs/config.example.yaml）：**

```yaml
app:
  name: math-top-backend
  port: 8080
  mode: debug

mysql:
  host: 127.0.0.1
  port: 3306
  user: root
  password: "your_password"
  dbname: math_top

redis:
  host: 127.0.0.1
  port: 6379
  password: ""
  db: 0

jwt:
  secret: "your-jwt-secret-change-it"
  expire_hours: 24

storage:
  upload_dir: ./storage/uploads
```

**预期效果：**
`configs/config.yaml` 可以被程序读取，字段齐全。

**如果出错：**
- YAML 缩进要用空格，不要用 Tab
- 密码如果是纯数字要加引号

## Step 03：编写配置读取模块

**目标：** 用 viper 把 yaml 读成 Go struct，供全项目使用

**涉及文件：**
- 创建 `internal/config/config.go`

**关键点：**
- 定义一个 `Config` struct，嵌套 `App`、`MySQL`、`Redis`、`JWT`、`Storage` 等子结构
- viper 读取后映射到 struct
- 暴露一个全局函数 `Load()` 或 `GetConfig()`

**关键代码片段：**

```go
type Config struct {
    App     AppConfig
    MySQL   MySQLConfig
    Redis   RedisConfig
    JWT     JWTConfig
    Storage StorageConfig
}

type AppConfig struct {
    Name string
    Port string  // 注意是 string，拼接 ":" 时方便
    Mode string
}
// ... 其他子结构
```

**预期效果：**
在 `main.go` 中调用 `cfg := config.Load()` 后，可以访问 `cfg.MySQL.Host`、`cfg.Redis.Port` 等字段。

**如果出错：**
- viper 读取路径问题，确保 `configs/config.yaml` 存在
- struct tag 写错：`mapstructure:"host"` 要跟 yaml key 一致

## Step 04：编写数据库初始化

**目标：** 连接 MySQL，配置连接池

**涉及文件：**
- 创建 `internal/bootstrap/db.go`

**关键点：**
- 拼接 DSN：`user:pass@tcp(host:port)/dbname?charset=utf8mb4&parseTime=True&loc=Local`
- 使用 `gorm.Open(mysql.Open(dsn), &gorm.Config{})`
- 设置连接池：`sqlDB.SetMaxOpenConns(100)`、`SetMaxIdleConns(10)`
- 初始化成功后打印日志

**关键代码片段：**

```go
func InitDB(cfg *config.Config) *gorm.DB {
    dsn := fmt.Sprintf("%s:%s@tcp(%s:%s)/%s?charset=utf8mb4&parseTime=True&loc=Local",
        cfg.MySQL.User, cfg.MySQL.Password, cfg.MySQL.Host, cfg.MySQL.Port, cfg.MySQL.DBName)
    db, err := gorm.Open(mysql.Open(dsn), &gorm.Config{})
    if err != nil {
        log.Fatalf("MySQL 连接失败: %v", err)
    }
    // 设置连接池...
    log.Println("MySQL 连接成功")
    return db
}
```

**预期效果：**
启动时终端打印 "MySQL 连接成功"。如果密码错误，会 panic 并提示连接失败。

**如果出错：**
- 检查本地 MySQL 是否在 3306 端口运行
- 检查数据库 `math_top` 是否已创建：`CREATE DATABASE math_top CHARACTER SET utf8mb4;`
- DSN 格式错误（密码特殊字符未转义）

## Step 05：编写 Redis 初始化

**目标：** 连接 Redis，确保连通性

**涉及文件：**
- 创建 `internal/bootstrap/redis.go`

**关键点：**
- 创建 `redis.NewClient(&redis.Options{...})`
- 连接后执行 `Ping`，确认 `rdb.Ping(ctx).Result()` 返回 `PONG`
- 初始化失败直接退出

**关键代码片段：**

```go
func InitRedis(cfg *config.Config) *redis.Client {
    rdb := redis.NewClient(&redis.Options{
        Addr:     fmt.Sprintf("%s:%s", cfg.Redis.Host, cfg.Redis.Port),
        Password: cfg.Redis.Password,
        DB:       cfg.Redis.DB,
    })
    if err := rdb.Ping(context.Background()).Err(); err != nil {
        log.Fatalf("Redis 连接失败: %v", err)
    }
    log.Println("Redis 连接成功")
    return rdb
}
```

**预期效果：**
启动时终端打印 "Redis 连接成功"。

**如果出错：**
- 检查本地 Redis 是否在 6379 端口运行：`redis-cli ping`
- 如果 Redis 没有密码，Password 设为空字符串 `""`

## Step 06：编写统一响应封装

**目标：** 所有接口返回统一 JSON 结构 `{code, message, data}`

**涉及文件：**
- 创建 `internal/response/response.go`

**关键点：**
- 定义 `Response` struct
- 提供便捷函数：`Success(c, data)`、`Error(c, code, message)`、`Page(c, list, total, page, pageSize)`
- HTTP 状态码统一返回 200，业务状态码放在 body 的 `code` 字段

**关键代码片段：**

```go
type Response struct {
    Code    int         `json:"code"`
    Message string      `json:"message"`
    Data    interface{} `json:"data"`
}

func Success(c *gin.Context, data interface{}) {
    c.JSON(200, Response{Code: 0, Message: "success", Data: data})
}

func Error(c *gin.Context, code int, message string) {
    c.JSON(200, Response{Code: code, Message: message})
}
```

**预期效果：**
后续 handler 中可以一行代码返回：`response.Success(c, gin.H{"status": "ok"})`

**如果出错：**
- `gin.Context` 在 JSON 之后不能再写入，确保每个 handler 只调用一次 response 函数

## Step 07：编写基础路由 + CORS + 日志恢复

**目标：** 注册 `/ping`、`/health`，配置跨域和 panic 恢复

**涉及文件：**
- 创建 `internal/router/router.go`
- 创建 `internal/bootstrap/router.go`
- 创建/修改 `cmd/server/main.go`

**关键点：**
- 使用 `gin.New()` 或 `gin.Default()`
- 注册 Recovery 中间件（Gin 自带）
- 注册 CORS 中间件（gin-contrib/cors 或自定义）
- 注册 `/ping` 和 `/health`
- `main.go` 的启动顺序：LoadConfig → InitDB → InitRedis → InitRouter → Run

**关键代码片段（internal/router/router.go）：**

```go
func Register(r *gin.Engine) {
    // 健康检查
    r.GET("/ping", func(c *gin.Context) {
        response.Success(c, gin.H{"message": "pong"})
    })
    r.GET("/health", func(c *gin.Context) {
        response.Success(c, gin.H{
            "service": "math-top-backend",
            "status":  "ok",
        })
    })
}
```

**关键代码片段（cmd/server/main.go）：**

```go
func main() {
    cfg := config.Load()
    db := bootstrap.InitDB(cfg)
    rdb := bootstrap.InitRedis(cfg)
    router := bootstrap.InitRouter(cfg, db, rdb)
    router.Run(":" + cfg.App.Port)
}
```

**预期效果：**
```bash
curl http://localhost:8080/ping
# 返回：{"code":0,"message":"success","data":{"message":"pong"}}

curl http://localhost:8080/health
# 返回：{"code":0,"message":"success","data":{"service":"math-top-backend","status":"ok"}}
```

**如果出错：**
- 端口被占用：检查 `lsof -i :8080`
- 依赖未导入：确保 bootstrap 和 config 包能正确引用
- 循环导入：response 包不要依赖其他业务包

## Step 08：添加结构化日志

**目标：** 替换 `log.Println`，使用结构化日志

**涉及文件：**
- 创建 `internal/bootstrap/logger.go`（可选，可简化）
- 或直接在 `main.go` 中初始化 `log/slog`

**关键点：**
- 推荐 Go 1.21+ 自带的 `log/slog`
- 设置 JSON 格式输出到终端，后续可扩展写入 `storage/logs`
- 在每次请求时打印请求方法、路径、耗时

**关键代码片段：**

```go
// main.go 顶部初始化
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
slog.SetDefault(logger)

// 在 bootstrap/router.go 中，给 Gin 加日志中间件
r.Use(gin.Logger())  // 或自定义中间件打印请求耗时
```

**预期效果：**
启动后每次请求终端显示：`[GIN] 2026/05/21 - GET /ping - 200 - 0.23ms`
