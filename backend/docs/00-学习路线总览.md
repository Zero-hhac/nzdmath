# 学习路线总览

本文档是整个后端开发项目的索引表，列出了从 0 到部署的全部阶段。每一个阶段都有明确的**目标**和**验收标准**。

> **使用方式**：先通读本文档建立全局认知，然后按编号依次阅读每个阶段的详细指南。每完成一个阶段，回到本文档的"验收标准"一栏，打勾确认后再进入下一阶段。

---

## 阶段速查表

| 阶段 | 文档 | 目标 | 验收标准 | 预计文件数 |
|---|---|---|---|---|

## 学习顺序建议

### 标准路线（推荐）

适合时间充裕，希望系统掌握后端开发的同学：

```
第一阶段 → 第二阶段 → 第三阶段 → 第四阶段 → 第五阶段 → 第六阶段 → 第七阶段
```

### 精简路线

适合想快速跑通一个完整项目，先建立信心的同学：

```
第一阶段 → 第二阶段 → 第三阶段 → 第四阶段 → 第七阶段
```

> 精简路线跳过了会员收藏细节、后台管理细节。完成后再按需回来补充。

## 每阶段的核心文件模板

为了方便你快速启动，各阶段涉及的核心文件类型如下（以 activity 模块为例）：

```text
// 每个业务模块的通用 5 件套
dto/activity_dto.go          // 请求/响应结构
cache/activity_cache.go       // Redis 缓存封装
repository/activity_repository.go  // 数据库查询
service/activity_service.go    // 业务逻辑
handler/activity_handler.go    // HTTP 接口处理
router/activity_router.go      // 路由注册
```

## 最终验收清单

完成所有阶段后，你应该能回答以下问题：

- [ ] 能独立用 Gin 搭建一个后端骨架
- [ ] 能合理组织 Go 项目目录（cmd/internal/configs/deployments）
- [ ] 能用 Gorm 建模和查询
- [ ] 能用 Redis 做登录态管理
- [ ] 能设计并实现 REST 风格接口（含分页、搜索、聚合）
- [ ] 能用 bcrypt 安全存储密码
- [ ] 能用 Docker Compose 跑本地联调
- [ ] 能用 Nginx 代理前后端
- [ ] 能把一个真实前端项目接上真实后端
