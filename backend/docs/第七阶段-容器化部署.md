## Step 01：编写 Dockerfile

**目标：** 把 Go 后端打包成 Docker 镜像

**涉及文件：**
- 修改 `Dockerfile`

**关键点：**
- 多阶段构建：第一阶段编译，第二阶段用轻量镜像运行
- 最终镜像只需要二进制文件和配置文件
- 暴露 8080 端口
- 设置正确的 WORKDIR

**关键代码片段：**

```dockerfile
# 第一阶段：编译
FROM golang:1.22-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN go build -o server cmd/server/main.go

# 第二阶段：运行
FROM alpine:latest

WORKDIR /app
COPY --from=builder /app/server .
COPY --from=builder /app/configs ./configs

# 创建上传目录
RUN mkdir -p /app/storage/uploads /app/storage/logs

EXPOSE 8080

CMD ["./server"]
```

**预期效果：**
```bash
docker build -t math-top-backend .
# 构建成功，无报错
```

**如果出错：**
- `go build` 失败：检查是否有未提交的依赖或编译错误
- Alpine 缺少时区数据：`RUN apk add --no-cache tzdata`

## Step 02：编写 docker-compose.yml

**目标：** 定义 MySQL + Redis + Backend + Nginx 四个服务

**涉及文件：**
- 修改 `docker-compose.yml`

**关键点：**
- 服务之间用服务名通信（不用 127.0.0.1）
- MySQL 数据挂卷，防止容器重建数据丢失
- Backend 依赖 MySQL 和 Redis（用 `depends_on`）
- Nginx 依赖 Backend
- 后端配置中的 `mysql.host` 和 `redis.host` 要改成服务名

**关键代码片段：**

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: math-top-mysql
    environment:
      MYSQL_ROOT_PASSWORD: your_password
      MYSQL_DATABASE: math_top
    volumes:
      - mysql_data:/var/lib/mysql
    ports:
      - "3306:3306"
    networks:
      - math-top-network

  redis:
    image: redis:7-alpine
    container_name: math-top-redis
    ports:
      - "6379:6379"
    networks:
      - math-top-network

  backend:
    build: .
    container_name: math-top-backend
    depends_on:
      - mysql
      - redis
    environment:
      - APP_PORT=8080
    volumes:
      - ./configs:/app/configs:ro
      - ./storage/uploads:/app/storage/uploads
      - ./storage/logs:/app/storage/logs
    networks:
      - math-top-network

  nginx:
    image: nginx:alpine
    container_name: math-top-nginx
    ports:
      - "80:80"
    volumes:
      - ./deployments/nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
      - ./storage/uploads:/usr/share/nginx/html/uploads:ro
      # 前端 dist 目录（打包后挂载）
      # - ../frontend/dist:/usr/share/nginx/html:ro
    depends_on:
      - backend
    networks:
      - math-top-network

volumes:
  mysql_data:

networks:
  math-top-network:
    driver: bridge
```

**预期效果：**
```bash
docker compose config
# 验证 compose 文件格式正确
```

## Step 03：编写 Nginx 配置文件

**目标：** Nginx 托管前端静态资源，并代理 `/api` 到后端

**涉及文件：**
- 创建 `deployments/nginx/default.conf`

**关键点：**
- `location /`：服务前端静态文件，SPA 需要 `try_files`
- `location /api/`：代理到 backend:8080
- `location /uploads/`：服务上传的文件（直接读静态目录）
- 开启 gzip 压缩
- 设置合理的 proxy timeout

**关键代码片段：**

```nginx
server {
    listen 80;
    server_name localhost;
    
    # 前端静态资源
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;  # SPA 路由支持
    }
    
    # 上传的文件
    location /uploads/ {
        alias /usr/share/nginx/html/uploads/;
        expires 7d;
    }
    
    # 后端 API
    location /api/ {
        proxy_pass http://backend:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
    
    # gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
}
```

**预期效果：**
配置文件语法正确：
```bash
nginx -t -c /path/to/default.conf
# 或在容器内：nginx -t
```

## Step 04：修改后端配置适配容器环境

**目标：** 让后端在容器内能连上 MySQL 和 Redis

**涉及文件：**
- 修改 `configs/config.yaml`（容器版本，可选单独创建）
- 或修改 `configs/config.yaml` 为通用配置

**关键点：**
- MySQL host 从 `127.0.0.1` 改为 `mysql`
- Redis host 从 `127.0.0.1` 改为 `redis`
- 端口保持默认
- 可以考虑用环境变量覆盖配置（进阶），第一版直接改 yaml 即可

**关键代码片段（configs/config.yaml）：**

```yaml
app:
  name: math-top-backend
  port: 8080
  mode: debug

mysql:
  host: mysql        # 容器内用服务名
  port: 3306
  user: root
  password: your_password
  dbname: math_top

redis:
  host: redis        # 容器内用服务名
  port: 6379
  password: ""
  db: 0

jwt:
  secret: "your-jwt-secret-change-it-in-production"
  expire_hours: 24

storage:
  upload_dir: ./storage/uploads
```

**预期效果：**
在容器内，backend 服务能通过服务名 `mysql` 和 `redis` 解析到正确 IP。

## Step 06：编写部署文档和环境变量管理

**目标：** 整理部署相关文档，分离敏感配置

**涉及文件：**
- 修改 `README.md`
- 创建 `.env.example`（敏感配置模板）

**关键点：**
- `.env` 文件放数据库密码、JWT 密钥等，**不要提交到 Git**
- `.env.example` 只放占位符，提交到 Git
- docker-compose.yml 可以用 `${MYSQL_ROOT_PASSWORD}` 引用环境变量
- README 中写明启动步骤

**关键代码片段（.env.example）：**

```bash
# 数据库
MYSQL_ROOT_PASSWORD=your_password_here
MYSQL_DATABASE=math_top

# JWT
JWT_SECRET=your-jwt-secret-here

# 其他
APP_ENV=production
```

**关键代码片段（README.md 部署章节）：**

```markdown
## 快速启动

1. 复制环境变量模板：
   ```bash
   cp .env.example .env
   # 编辑 .env 填入真实密码
   ```

2. 启动所有服务：
   ```bash
   docker compose up --build
   ```

3. 访问 http://localhost

## 目录说明
- `configs/`：应用配置
- `deployments/`：Docker 和 Nginx 配置
- `storage/uploads/`：上传文件存储
```

**预期效果：**
- 新机器上克隆项目后，按 README 步骤能快速启动
- 敏感信息不会意外提交到 Git

## 后续可扩展方向

完成以上 7 个阶段后，项目已是一个完整可运行的系统。如果你希望继续深入，可以考虑：

1. **HTTPS**：为 Nginx 配置 SSL 证书（Let's Encrypt）
2. **CI/CD**：GitHub Actions 自动构建和部署
3. **监控**：接入 Prometheus + Grafana 监控服务状态
4. **日志收集**：ELK 或 Loki 收集和分析日志
5. **对象存储**：将文件上传迁移到阿里云 OSS / AWS S3
6. **数据库优化**：加索引、读写分离、连接池调优
7. **缓存升级**：Redis 集群、本地缓存（如 bigcache）
8. **消息队列**：引入 RabbitMQ / Kafka 处理异步任务（如发送邮件）
