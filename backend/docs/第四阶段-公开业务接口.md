## Step 01：封装公共分页逻辑

**目标：** 让所有列表接口共享同一套分页逻辑，避免重复代码

**涉及文件：**
- 创建 `internal/dto/common_dto.go`
- 创建 `internal/service/pagination.go`（或放在 pkg 中）

**关键点：**
- 分页请求参数：`page`（默认 1）、`page_size`（默认 10，最大 100）
- 分页响应结构：`list`、`total`、`page`、`page_size`
- 计算 `offset = (page - 1) * page_size`
- GORM 查询：`db.Offset(offset).Limit(pageSize).Find(&list)`

**关键代码片段：**

```go
// internal/dto/common_dto.go
package dto

type PageRequest struct {
    Page     int `form:"page" json:"page" binding:"min=1"`
    PageSize int `form:"page_size" json:"page_size" binding:"min=1,max=100"`
}

func (p *PageRequest) GetOffset() int {
    if p.Page <= 0 {
        p.Page = 1
    }
    if p.PageSize <= 0 {
        p.PageSize = 10
    }
    return (p.Page - 1) * p.PageSize
}

type PageResponse struct {
    List     interface{} `json:"list"`
    Total    int64       `json:"total"`
    Page     int         `json:"page"`
    PageSize int         `json:"page_size"`
}
```

**预期效果：**
所有 handler 可以统一解析分页参数：
```go
var req dto.PageRequest
if err := c.ShouldBindQuery(&req); err != nil {
    response.Error(c, 400, "分页参数错误")
    return
}
```

**关键代码片段（EventRepository）：**

```go
func (r *EventRepository) List(category, keyword string, page, pageSize int) ([]model.Event, int64, error) {
    var events []model.Event
    var total int64
    
    db := r.db.Model(&model.Event{}).Where("status = ?", 1)
    if category != "" {
        db = db.Where("category = ?", category)
    }
    if keyword != "" {
        db = db.Where("title LIKE ?", "%"+keyword+"%")
    }
    
    db.Count(&total)
    err := db.Offset((page - 1) * pageSize).Limit(pageSize).Order("created_at DESC").Find(&events).Error
    return events, total, err
}

func (r *EventRepository) FindByID(id uint) (*model.Event, error) {
    var event model.Event
    err := r.db.Where("id = ? AND status = ?", id, 1).First(&event).Error
    if err != nil {
        return nil, err
    }
    return &event, nil
}
```

**关键代码片段（EventHandler 列表）：**

```go
func (h *EventHandler) List(c *gin.Context) {
```

- 上传目录：`storage/uploads/`（已在第一阶段创建）
- 生成文件 URL：`/uploads/filename`（后续 Nginx 会代理静态文件）
- 下载次数自增：访问详情时 `download_count++`

**关键代码片段（文件上传 handler）：**

```go
func (h *ResourceHandler) Upload(c *gin.Context) {
    file, err := c.FormFile("file")
    if err != nil {
        response.Error(c, 400, "上传文件失败")
        return
    }
    
    // 生成唯一文件名
    ext := filepath.Ext(file.Filename)
    filename := fmt.Sprintf("%d%s", time.Now().UnixNano(), ext)
    dst := filepath.Join("storage/uploads", filename)
    
    if err := c.SaveUploadedFile(file, dst); err != nil {
        response.Error(c, 500, "保存文件失败")
        return
    }
    
    fileURL := "/uploads/" + filename
    response.Success(c, gin.H{"file_url": fileURL, "filename": file.Filename, "size": file.Size})
}
```

**预期效果：**
- 列表接口支持按 type 筛选
- 上传文件后 `storage/uploads/` 下出现新文件
- 资源详情接口返回包含 `file_url` 的完整数据

## Step 06：添加 Redis 缓存（公开数据）

**目标：** 对高频读的公开接口加 Redis 缓存，减少数据库压力

**涉及文件：**
- 创建 `internal/cache/home_cache.go`
- 修改 `internal/service/home_service.go`
- 创建 `internal/cache/event_cache.go`（可选）

**关键点：**
- 首页聚合数据缓存 5-10 分钟（更新不频繁）
- 活动/资源/资讯列表缓存 1-2 分钟
- 详情接口缓存 5 分钟
- 后台更新内容后，主动删除缓存（或等 TTL 过期）
- 使用 JSON 序列化存 Redis

**关键代码片段（HomeCache）：**

```go
func (c *HomeCache) GetHomeData() (*dto.HomeResponse, error) {
    val, err := c.rdb.Get(context.Background(), "cache:home:data").Result()
    if err == redis.Nil {
        return nil, nil  // 缓存未命中
    }
    if err != nil {
        return nil, err
    }
    
    var data dto.HomeResponse
    if err := json.Unmarshal([]byte(val), &data); err != nil {
        return nil, err
    }
    return &data, nil
}

func (c *HomeCache) SetHomeData(data *dto.HomeResponse, expire time.Duration) error {
    bytes, _ := json.Marshal(data)
    return c.rdb.Set(context.Background(), "cache:home:data", string(bytes), expire).Err()
}
```

**在 Service 中使用：**

```go
func (s *HomeService) GetHomeData() (*dto.HomeResponse, error) {
    // 先查缓存
    if cached, err := s.cache.GetHomeData(); err == nil && cached != nil {
        return cached, nil
    }
    
    // 缓存未命中，查数据库
    data, err := s.getHomeDataFromDB()
    if err != nil {
        return nil, err
    }
    
    // 写入缓存
    s.cache.SetHomeData(data, 5*time.Minute)
    return data, nil
}
```

**预期效果：**
- 第一次访问首页，Redis 无 key，查数据库
- 第二次访问首页，Redis 有 `cache:home:data`，响应更快
- 后台发布新内容后，下一次请求 TTL 过期后更新

```go
type CreateEventRequest struct {
    Title    string    `json:"title" binding:"required,min=2,max=200"`
    Summary  string    `json:"summary" binding:"max=500"`
    Content  string    `json:"content" binding:"required"`
    Category string    `json:"category" binding:"required,oneof=讲座 比赛  workshop"`
```
